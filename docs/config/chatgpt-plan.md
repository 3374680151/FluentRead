# ChatGPT 套餐接入状态

**流畅阅读的当前公开版本尚未开放 ChatGPT 登录接入。** 翻译服务目录中不显示此入口，所需的 OpenAI 申请与批准尚未完成。

请在**设置 → 翻译服务**中选择可用服务。若以前保存过 ChatGPT 套餐服务或模型，为需要使用的功能重新选择服务即可，无需删除旧配置；已完成的译文保留。

ChatGPT Plus 或 Pro 订阅不代表此功能已在流畅阅读开放，也不等同于 OpenAI API 额度。接入方式见 [OpenAI 官方说明](https://developers.openai.com/siwc/quickstart)，维护者申请入口见[申请 ChatGPT 接入](/guide/chatgpt-application)。
