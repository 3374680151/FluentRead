# Zotero 文献翻译

流畅阅读提供实验性的 Zotero 桌面插件，可翻译 PDF、阅读时的选中文字，并保存译文附件或双语笔记。插件与浏览器扩展分别安装和配置。

## 安装

1. 在流畅阅读仓库根目录运行 `pnpm build:zotero`，生成 `integrations/zotero/dist/fluentread-zotero.xpi`。
2. 在 Zotero 中打开 **工具 → 插件**，点击齿轮菜单，选择 **从文件安装插件**，安装 XPI。
3. 打开流畅阅读工作台，配置语言和服务。

目前需要从源码构建，尚无自动更新渠道。兼容声明面向 Zotero 7–10；现有验证以 macOS 的 Zotero 10 为主，其他版本和平台仍需验证，请先用测试文献库试用。

## 配置翻译

默认自动识别原文，目标语言为简体中文。可选择：

- **微软翻译**：无需模型 API Key。
- **OpenAI 兼容服务**：填写 Chat Completions 地址、模型和 API Key。远程地址使用 HTTPS，本地模型可用 HTTP 回环地址。
- **术语**：指定当前文档中的固定译法。
- **输出**：选择双语或仅译文 PDF，以及完成后是否自动打开。

插件单独保存配置，不读取或同步浏览器扩展的密钥。

## 翻译与继续阅读

1. 在文献库中选择带本地 PDF 的条目，或直接选择 PDF 附件，从流畅阅读菜单加入队列。
2. 在工作台查看进度。文档依次处理；暂停会保留已完成部分，继续时只处理剩余段落，失败后可重试。
3. 完成后，译文 PDF 保存为原条目的新附件，原文件保留。独立 PDF 的结果保留在原文献库和分类中，也可另存按页组织的双语笔记。

关闭或停用插件后，未完成任务会暂停；主动继续后才发送新请求。修改语言或服务只影响新任务，已有任务保留创建时的配置。原 PDF 内容发生变化时，请新建任务。清除任务记录不会删除已生成的 PDF 或笔记。

只翻译一段文字时，在 Zotero PDF 阅读器中选中它，使用流畅阅读入口；服务与语言沿用工作台配置。

## 文件与数据

目前仅支持有文字层的 PDF。扫描件需先做 OCR；不支持 EPUB、网页文献库和移动端。译文排版、页数可能与原文不同，原文件批注不会自动迁移。

PDF 在本机解析和生成；发起翻译后，文字与必要指令发送给所选服务，不会将整份 PDF 上传到流畅阅读云端，插件不收集遥测。设置和进度位于 Zotero 配置目录的 `fluentread/` 中，密钥单独保存在本地 `credentials.json`，不写入任务或笔记；该文件未加密。

首次导出可能下载约 5 MB 的开放许可字体，校验后缓存复用。字体请求不包含文献内容、译文或密钥。

无法保存时，检查文献库是否只读；找不到 PDF 时，先在 Zotero 下载附件或重新定位文件。源码及构建说明见 [Zotero 插件目录](https://github.com/FluentRead/FluentRead/tree/main/integrations/zotero)。
