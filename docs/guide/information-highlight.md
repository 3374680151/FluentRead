# 智能高亮

在正文中标出词语，方便扫读和回看。文字仍可正常选择、复制，页面排版保持原样。它与对应原文和译文的“逐句高亮”分别设置。

<GuideVisual kind="highlight" />

## 使用

1. 打开**设置 → 翻译设置 → 智能高亮**，选择分析方式和外观，查看左侧预览。
2. 打开**启用快捷键**，再到网页上按 **Alt+H**（Mac 为 Option+H）开启当前页高亮，再按一次关闭。快捷键默认关闭，可自行更换。
3. 希望网页都自动高亮时，打开**所有页面自动高亮**。已打开及之后访问的网页都会生效，关闭即可清除。

只用快捷键开启时，刷新或离开页面后恢复关闭，其他页面不受影响。流畅阅读 PDF 阅读器也沿用自动高亮设置，还可使用工具栏的**智能高亮**按钮开关当前文档；扫描页没有可选文字时无法高亮。

## 两种模式

| 模式 | 适合什么 | 是否下载模型 |
| --- | --- | --- |
| 关键词 | 快速找出主题词、专名和不常见的词 | 不需要 |
| 预测意外度 | 留意在上下文中不容易预测的词 | 需要下载 Qwen2.5 0.5B Base，约 490 MB |

两种模式都在本机分析正文。下载模型会连接模型托管站点，但不会把网页文字发给它。

“预测意外度”高只表示模型较难预测这个词，**不代表更重要或更正确**。人名、错字和罕见词也可能被突出显示，阅读时仍需留意未高亮的否定和条件。

## 外观与性能

默认使用**深浅渐层**，颜色深浅表示分析得到的层级。还可以选择柔和底色或细下划线，调整密度、配色和颜色浓度。在预览右上角切换**高亮 / 原文**，比较哪种方式更适合阅读。

正文中看得见的段落会优先处理，滚动后继续补充其他段落。代码、编辑器、表单、公式和导航等区域不会上色。关闭功能会清除标记并停止本次分析；不支持高亮显示的浏览器会保留正常页面并说明原因。

<details class="guide-details">
<summary>下载本地模型与失败恢复</summary>

选择**预测意外度**后，点击模型卡片的**下载模型**并确认，才会开始下载；关闭确认框不会下载。暂停或中断后，可点击**继续下载**并确认。下载完成后可离线分析，也可点击**删除模型**并确认来释放空间。

模型模式需要设备和浏览器支持本地模型运行。未下载模型或设备无法运行时，当前页会改用关键词方式并提示原因，设置中的选择不变，正文不会自动上传到云端。

存储、校验或模型启动失败时，按提示重试或切换为**关键词**。已有完整模型不会重复下载。旧 Qwen3 模型已停用；旧设置会保留开关和外观，并转为 Qwen2.5 Base，下载新模型仍需确认。

</details>
