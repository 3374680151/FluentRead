# 双语分享卡片

将划词翻译的原文和译文排成图片，方便保存或分享。卡片在本机生成，不会为此再次翻译或上传文字。

<GuideVisual kind="share" />

## 制作一张卡片

1. 选中文字，打开划词翻译卡片，点击 **制作卡片**。
2. 选择样式。需要修改内容时，打开 **编辑摘录**；调整尺寸、字号或双语顺序时，打开 **更多设置**。
3. 检查预览，点击 **保存图片** 或 **复制图片**。

此入口位于划词翻译结果中，悬浮翻译和网页全文翻译不提供制作按钮。修改摘录只影响这张卡片。

## 调整与导出

- **样式**：可选珊瑚、晴空、流光、月白、抹茶、书页、落日和蓝图。
- **尺寸**：自适应适合长摘录；方形适合短句。方形放不下时，缩短文字或改为自适应，避免内容溢出。
- **来源与标识**：来源默认显示网站域名，可改为作者或隐藏；品牌标识也可调整。

预览与导出使用相同排版。样式偏好会保留，摘录和图片不会写入扩展配置；富文本和公式按纯文字处理。

复制失败时，使用 **保存图片**。下载提示表示已开始下载，可在浏览器下载列表中确认文件。
