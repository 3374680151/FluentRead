# 快捷键与触发方式

使用快捷键翻译、恢复原文或复制段落。Mac 键盘上的 Alt 通常标为 Option。

<GuideVisual kind="shortcuts" />

## 常用操作

| 操作 | 默认方式 |
| --- | --- |
| 翻译当前段落 | 鼠标放在段落上，按 **Control** |
| 翻译页面 / 恢复原文 | **Alt+T** |
| 圈选画面文字 | 按一次 **Shift+Z**，再拖动区域 |
| 复制鼠标所在段落 | 鼠标放在段落上，按 **Alt+C** |
| 只翻译网页的一部分 | 点击扩展菜单的**局部**；也可开启 **Alt+R** |
| 划词翻译 | 开启功能后，选中文字并点击附近图标 |
| 依次点击起点和终点选中文字 | 在划词设置开启**两点选取**，再按 **Alt+Shift+S** |

## 在哪里修改？

在扩展菜单打开**鼠标悬停翻译**或**划词翻译**，进入对应设置更换触发方式。圈选快捷键在**图片翻译 → 圈选翻译**中修改。

录制组合键时，按住 Ctrl、Alt/Option 或 Shift，再按字母或功能键，完成后确认保存。只按修饰键不会完成录制；取消或切换设置分类会保留原设置。组合键与其他已启用功能冲突时，需要换一个再确认。

## 局部翻译与独立方案

局部翻译快捷键默认关闭，在**设置 → 翻译设置 → 局部翻译**中开启。

1. 按快捷键后移动鼠标预览区域，单击锁定；也可按住左键划过多个段落，松开锁定。
2. 使用 **↑/↓** 或工具条调整范围，按 **Enter** 或点击**翻译所选区域**确认。
3. 选中已翻译区域后再次确认，可恢复原文。按 **Esc**、右键或同一快捷键退出。

悬浮、全文和局部翻译各可添加最多 8 个独立方案，分别选择服务、模型、语言和显示方式。主快捷键关闭时，已开启的独立方案仍可使用。详见[局部翻译](/guide/features#局部翻译)。

## 两点选取

在**设置 → 划词翻译 → 触发与显示**中开启**两点选取**。按 **Alt+Shift+S** 后，依次点击正文起点、终点，即可跨行或反向选取，无需按住鼠标。第二次点击后保留浏览器原生选区，翻译入口沿用原来的划词触发方式。

按 **Esc**、再次按快捷键或离开页面可取消。点击链接、按钮或编辑区时，会退出选择并保留网页原本的操作。点击空白或同一位置会提示重试，已确定的起点会保留；超过 4096 字符或包含受保护内容时，按提示更换终点。

快捷键与其他功能冲突时，设置行会提示，点击按键名称即可更换。输入框和可编辑区域中不会启动两点选取。触屏仍使用原生长按选区；两点选取、局部翻译和圈选同时只保留一种选择模式。

<details class="guide-details">
<summary>段落复制与划词入口</summary>

在**设置 → 翻译设置 → 段落复制**中选择复制内容：

| 内容 | 行为 |
| --- | --- |
| 跟随页面显示（默认） | 已翻译时跟随双语或仅译文显示，未翻译时复制原文 |
| 原文 | 始终复制网页原文 |
| 译文 | 尚未翻译时复制原文并提示 |
| 原文和译文 | 两段一起复制，顺序跟随译文显示位置 |

复制后会提示内容和字数。输入框或可编辑区域不触发，**Ctrl+C** 仍用于复制选中文字。

划词可选图标、小点、直接弹出、悬停图标、快捷键或**仅右键菜单**。仅右键菜单不会显示浮动图标；选中文字后右键选择**翻译选中文本**，并保持**设置 → 右键菜单**中的总开关与选区入口开启。

</details>

<details class="guide-details">
<summary>独立方案的服务与模型</summary>

方案跟随默认服务时，选择独立模型会同时固定当前服务。清空模型只恢复该服务的默认模型；要重新跟随网页默认服务，请选择**跟随默认**。改换服务会清空旧模型。谷歌翻译使用双语显示，切回其他服务后恢复已保存的显示偏好。

</details>

## 没反应或与网页冲突

先从扩展菜单确认功能可用，再检查是否与浏览器、输入法或网页快捷键冲突。部分按键不会在输入框中触发，浏览器内部页和扩展商店通常也不允许翻译。

自定义组合键按录制时键盘布局产生的字符匹配；Mac 的 Option 产生特殊符号时，按对应物理按键匹配。浏览器的扩展快捷键管理页只控制浏览器列出的命令，其他触发方式在流畅阅读中设置。

网页更新后入口消失时，可重新选中文字。仍不显示，请反馈网址、浏览器、扩展版本和触发方式。
