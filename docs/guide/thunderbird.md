# 在 Thunderbird 中翻译邮件

流畅阅读提供独立的 Thunderbird 插件，可翻译正在阅读的邮件正文。它与 Firefox 扩展分别保存设置。

<GuideVisual kind="email" />

## 构建与安装

1. 在流畅阅读源码目录运行 `pnpm build:thunderbird`，得到 `.output/fluent-read-<版本>-thunderbird.xpi`。
2. 在 Thunderbird 140 或更高版本中打开 **附加组件和主题**，选择 **从文件安装附加组件**，安装这个 XPI。
3. 打开主工具栏的流畅阅读按钮，选择翻译服务、语言和显示模式。

## 阅读邮件

打开邮件，点击邮件工具栏的 **翻译 / 恢复当前邮件**，在原文与翻译视图间切换。安装前已经打开的邮件需要重新打开，才能显示操作入口。开启全局自动翻译后，新打开的邮件会自动翻译。

翻译会将邮件文字发送给所选服务，请按邮件内容选择合适的服务。插件只处理正在显示的邮件正文，不处理撰写窗口；目前不提供图片识别、区域翻译和本地语音播放。
