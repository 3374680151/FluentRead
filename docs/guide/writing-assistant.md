# 写作助手

在 Gmail 和 GitHub 的编辑器旁起草或完善回复。先检查结果，再插入编辑器，由你决定何时发送。

<GuideVisual kind="writing" />

## 开始前

打开**设置 → 写作助手**，开启功能并选择 AI 服务与模型。缺少连接信息时，先到[翻译服务](/config/translation-engines)中配置。输出语言、对照语言、篇幅和语气可在设置中保存，也可在写作时临时调整。

## 起草一条回复

1. 在支持的 Gmail 或 GitHub 页面中打开回复编辑器，点击旁边的写作入口。
2. 有草稿时，助手会帮你完善；没有草稿时，使用当前讨论起草。新邮件没有参考内容时，先填写收件人、目的和要点。
3. 生成后核对人名、事实和语气，需要时补充要求再调整。
4. 点击**插入回复**放回当前编辑器，或**复制回复**后自行粘贴。
5. 在原网站检查并发送。写作助手不会自动发送邮件或评论。

原编辑器在生成期间发生变化时，请先核对新内容，避免插入时覆盖。复杂格式可以通过复制、粘贴自行保留。

## 插入双语回复

选择正文语言和不同的对照语言，等待对应的译文完整生成。**插入回复**只插入正文；旁边菜单中的**插入双语回复**会依次插入正文和对照译文。

GitHub 中保留 Markdown 格式，Gmail 中使用纯文本。

## 完善已有草稿

先在回复框写下内容，再打开写作助手，可按需要调整语言、长度和语气。修改参考内容后也可重新起草。

## 参考内容与停止生成

生成前检查**参考内容**中的草稿和可见的讨论或邮件。可选学习记忆沿用已保存的开关，无痕窗口不读取。

点击停止、关闭面板或离开页面会停止当前生成，保留已生成的正文。点击面板外可暂时收起；重新打开同一编辑器旁的入口，可接着查看本次草稿和结果。编辑器已被修改、更换编辑器或跳转页面后，会重新读取当前内容。

草稿和参考内容只在本页会话中保留。

## 调整或关闭入口

入口旁的菜单可关闭本次入口、在当前网站禁用，或关闭整个功能。在**设置 → 写作助手**中可恢复被禁用的网站，已保存的服务与风格偏好仍会保留。

</details>

## 数据去向

主动生成或调整时，必要的参考文字、草稿、指令和允许使用的学习记忆会发送给所选 AI 服务。详见[隐私政策](/guide/privacy)。
