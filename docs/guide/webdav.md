# WebDAV 云备份

以坚果云为例，把流畅阅读配置保存到自己的网盘，再到其他浏览器或设备恢复。云备份只在你手动操作时访问服务器，不会随设置修改自动上传。

<GuideVisual kind="webdav" />

## 在坚果云生成应用密码

1. 登录[坚果云网页版](https://www.jianguoyun.com/)。
2. 进入右上角**账户信息 → 安全选项 → 第三方应用管理**。
3. 点击**添加应用密码**，名称可填 `FluentRead`，生成并复制密码。

连接时使用这个应用密码，不要使用坚果云登录密码。入口见[坚果云官方说明](https://help.jianguoyun.com/?p=2064)。

## 设置 WebDAV 连接

打开**设置 → 备份与恢复 → 云备份**，选择 **WebDAV → 设置 WebDAV**。

<img src="/guides/webdav/cloud-backup.png" alt="流畅阅读云备份中的 WebDAV 选项与设置按钮" width="2248" height="948" loading="lazy" />

图中敏感配置已开启；首次使用时默认关闭。

| 字段 | 坚果云填写内容 |
| --- | --- |
| WebDAV 目录地址 | `https://dav.jianguoyun.com/dav/` |
| 用户名 | 坚果云账号邮箱，例如 `yourname@example.com` |
| 应用密码 | 上一步生成的应用密码 |

请完整复制地址，不要使用首页、分享链接或文件地址，也不必追加 `FluentRead/` 或提前创建该文件夹。参数见[坚果云官方说明](https://help.jianguoyun.com/?p=5677)。

点击**测试连接**，成功后**测试并保存**。这两个操作都不上传文件；测试只检查目录能否访问，不保证写入权限。保存的连接仅在当前设备使用。

## 第一次保存

1. 确认备份范围：**基础配置**始终开启；**敏感配置**默认关闭。
2. 需要迁移 API Key、翻译服务、模型或私密提示词时，打开敏感配置，阅读风险、勾选并点击**同意并开启**。选择会持续保存，直到手动关闭。
3. 点击**立即与WebDAV同步**，检查账号、范围和预览，再点击**保存到云端**。
4. 出现 **WebDAV 配置同步完成**后，检查账号、地址和上次同步时间。

扩展在确认首次保存后创建：

```text
FluentRead/fluentread-config.encrypted.json
```

以后同步会更新这份文件。首次连接发现已有备份时，先选择要恢复、保存还是合并，避免用新设备覆盖原备份。

备份在本机加密，无需另设备份密码；加密使用固定公开应用口令，**拿到文件的人仍可解密**。请保护账号、目录权限和设备，避免分享文件。坚果云应用密码用于登录网盘，不是备份加密密码。

## 在其他设备恢复或合并

1. 在新设备安装流畅阅读，建议两端更新到最新版。
2. 配置相同的坚果云目录与账号，可为新设备单独生成应用密码，再点击**测试并保存**。连接参数不随备份迁移。
3. 如需恢复已备份的密钥，在新设备也开启**敏感配置**并确认风险。
4. 点击**立即与WebDAV同步 → 恢复云端配置 → 继续**，检查修改，再点**恢复到本机**。

两端一致时，点击**完成同步**即可。需要用当前设备更新网盘时选**保存本机配置**；希望保留两端修改时选**逐项合并**，处理冲突后点击**确认并同步**。

基础范围恢复或合并会保留本机密钥与连接。云端只有基础配置时，开启敏感选项也不能恢复未备份的密钥。云备份不包含单词本、聊天记录和用量统计；迁移学习数据请用[本地完整备份](/config/backup-sync#本地完整备份)。

预览有效 10 分钟。取消或离开设置会结束预览；配置或文件变化后需要重新预览。请依次操作多台设备，避免同时同步覆盖备份。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 用户名或密码不正确 | 使用账号邮箱与第三方应用密码；密码已撤销时重新生成，并通过修改连接更新 |
| 目录不存在或无效 | 核对 `https://dav.jianguoyun.com/dav/`，不要用首页或分享链接 |
| 测试成功，却没有备份 | 还需手动同步、检查预览并确认保存 |
| 恢复后缺少密钥或翻译服务 | 检查原备份是否包含敏感配置，以及新设备的敏感开关 |
| 云端备份已变化 | 检查其他设备，重新预览 |
| 无法连接或请求过于频繁 | 检查网络与地址，稍后重试，避免连续点击测试 |
| 存储不足或文件过大 | 清理网盘或改用本地备份；配置 JSON 上限 20 MiB，密文上限 32 MiB |

坚果云的访问限制以[官方说明](https://help.jianguoyun.com/?p=2064)为准。

## 换账号、停止使用和删除

**修改连接**可更换地址、账号或密码。地址和用户名不变时，密码留空保留原值；修改地址或用户名需重新输入密码，旧预览失效。

**清除连接设置**只移除本机连接、应用密码和同步记录，保留本机配置与云端文件。撤销访问需在坚果云**第三方应用管理**撤销对应密码。

**删除云端备份**会要求核对账号和服务器，输入**确定删除**后点击**删除备份**。只删除固定备份文件，保留本机配置、API Key、连接和目录内其他文件，并清除本机同步记录。取消不删除；文件已不存在时点击**完成**。

回收站、历史版本和其他设备副本需另行清理。卸载、撤销密码或清除连接不会删除服务器文件，之后同步仍可重新创建备份。

## 本次同步范围

基础配置不上传敏感连接、私密提示词及未知字段。开启敏感配置后的选择在当前浏览器持续保存，取消、失败或切换账号不会关闭；恢复仍以文件实际内容为准。关闭开关或仅恢复基础配置不会清除旧文件的敏感信息，确认保存或合并基础配置只更新当前文件，不清理服务商历史版本。

新基础备份采用 v2，旧扩展需升级读取；完整敏感备份仍用 v1。数据范围与保护方式见[隐私政策](/guide/privacy#webdav-云备份)。

## 准备服务器连接

其他网盘或 NAS 使用服务商提供的已有目录地址，需要 Basic 鉴权与读取、创建目录、写入权限，删除还需 `DELETE`。例如 [Nextcloud](https://docs.nextcloud.com/server/latest/user_manual/en/files/access_webdav.html) 常用 `https://cloud.example.com/remote.php/dav/files/你的用户名/`。

优先用有效 HTTPS 证书和独立应用密码。HTTP 不保护用户名、密码或文件传输，需额外确认。地址不要包含凭据或查询参数；扩展不携带密码跟随重定向，请填写最终目录地址。连接测试后仍需实际保存与恢复一次，确认兼容。

## 云端版本保护

有强 ETag 时使用条件写入；缺少时先核对内容，再使用服务器的可用版本或文件存在性条件。写入后读回验证，发现文件变化会中止。内容核验不能完全防止同时写入，请勿同时操作多台设备。无法安全核验删除时，可到服务商页面手动删除固定文件。
