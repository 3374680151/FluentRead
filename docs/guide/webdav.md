# WebDAV 云备份

更新日期：2026 年 10 月 25 日。

通过 WebDAV，可以把流畅阅读的配置保存到自己的网盘，并在其他浏览器或设备上恢复。下面以**坚果云**为例，完成连接、首次备份和换设备恢复。

入口位于**设置 → 备份与恢复 → 云备份**。备份由你手动发起；修改设置后，需要再次同步才会更新云端文件。此功能适用于浏览器扩展，油猴脚本请使用[本地完整备份](/config/backup-sync#本地完整备份)。

## 在坚果云生成应用密码

1. 登录[坚果云网页版](https://www.jianguoyun.com/)。
2. 点击右上角的账户名，进入**账户信息 → 安全选项**。
3. 找到**第三方应用管理**，点击**添加应用密码**。
4. 应用名称可填写 `FluentRead`，点击**生成密码**，复制生成的应用密码。

应用密码用于让流畅阅读访问坚果云。填写连接时请使用这个密码，**不要填写坚果云登录密码**。具体入口见[坚果云官方的应用密码说明](https://help.jianguoyun.com/?p=2064)。

## 设置 WebDAV 连接

打开流畅阅读的**设置 → 备份与恢复 → 云备份**，选择 **WebDAV**，点击左下方的**设置 WebDAV**。

<img src="/guides/webdav/cloud-backup.png" alt="流畅阅读云备份页面中的 WebDAV 选项和设置 WebDAV 按钮" width="2248" height="948" loading="lazy" />

图中已开启敏感配置；首次使用时，该选项默认关闭。

在 **WebDAV 连接设置**中填写：

| 字段 | 坚果云填写示例 |
| --- | --- |
| WebDAV 目录地址 | `https://dav.jianguoyun.com/dav/` |
| 用户名 | 你的坚果云账号邮箱，例如 `yourname@example.com` |
| 应用密码 | 上一步在坚果云生成的应用密码 |

地址、账号和密码的填写规则也可参照[坚果云官方的 WebDAV 参数说明](https://help.jianguoyun.com/?p=5677)。请完整复制地址中的 `https://` 和 `/dav/`，不要填写坚果云首页、分享链接或备份文件地址。

使用上表中的地址时，**不必提前创建 `FluentRead` 文件夹，也不必在地址后追加 `FluentRead/`**。扩展会在你确认首次保存时创建自己的子目录。

填写后，点击**测试连接**；测试成功，再点击**测试并保存**。

这两个按钮都只检查目录是否可访问，不会上传备份，也不能保证账号具有写入权限。**测试并保存**会把连接信息保存到当前设备，下一步才是真正备份。

## 第一次保存

保存连接后，先选择需要备份的内容：

| 选项 | 包含内容 | 默认状态 |
| --- | --- | --- |
| 基础配置 | 语言、外观、快捷键、网站规则等普通设置 | 始终开启 |
| 敏感配置 | API Key、服务与模型、连接参数、私密提示词等 | 关闭，按需开启 |

只迁移日常设置时，保持**敏感配置**关闭即可。需要一并迁移翻译服务和密钥时，打开该选项，阅读风险、勾选确认，再点击**同意并开启**。开启后，当前浏览器后续的手动同步会继续使用这一范围，直到你手动关闭。

备份上传前会在本机加密，无需另设备份密码；但加密使用固定公开应用口令，**拿到文件的人仍可解密**。请保护坚果云账号和目录权限，避免分享备份文件。坚果云应用密码用于访问网盘，不是备份的加密密码。

1. 点击**立即与WebDAV同步**。
2. 云端尚无备份时，预览会提示将这台设备的配置保存到云端。
3. 核对账号、同步范围和变更内容，点击**保存到云端**。
4. 出现 **WebDAV 配置同步完成**后，查看操作区右侧的账号、服务器地址和上次同步时间。

使用坚果云默认地址时，备份文件位于网盘中的：

```text
FluentRead/fluentread-config.encrypted.json
```

同一目录保存一份当前配置备份。以后修改设置后，再次手动同步、检查预览并确认，即可更新这份文件。若首次连接就发现已有备份，请按下一节选择同步方向，确认后再操作。

## 在其他设备恢复或合并

1. 在另一台设备或另一个浏览器中安装流畅阅读，建议两端都更新到最新版。
2. 进入同一云备份入口，选择 **WebDAV**，重新填写相同的坚果云目录地址和账号。可为这台设备单独生成一个应用密码。
3. 点击**测试并保存**。用于连接坚果云的地址、用户名和应用密码只保存在本机，不会随云备份迁移。
4. 如果原备份包含敏感配置，并且希望恢复其中的密钥，在新设备上也开启**敏感配置**并完成风险确认。
5. 点击**立即与WebDAV同步**，读取云端备份。
6. 选择**恢复云端配置**，点击**继续**，检查将发生的修改，再点击**恢复到本机**。

如果提示“本机与云端配置已一致”，点击**完成同步**即可，无需重复恢复。

查看预览时，根据需要选择：

| 操作 | 适用情况 |
| --- | --- |
| 恢复云端配置 | 把云端已有设置恢复到当前设备，换设备时通常选这一项 |
| 保存本机配置 | 用当前设备的配置更新云端备份 |
| 逐项合并 | 两端都有需要保留的修改，逐项选择冲突使用本机值还是云端值，最后点击**确认并同步** |

普通范围的恢复或合并会保留本机密钥、翻译服务、地址和自定义连接。**云端只有基础配置时，即使新设备开启敏感配置，也无法恢复未备份的密钥**。云备份不包含单词本、聊天记录和用量统计；迁移学习数据请使用[本地完整备份](/config/backup-sync#本地完整备份)。

预览有效期为 10 分钟。点击**取消**或离开设置会结束预览；确认前若本机配置或云端文件发生变化，需要重新预览。界面提示“为避免云端备份被覆盖，请勿同时在多台设备上同步”时，请等一台设备完成后，再操作另一台。

## 常见问题

| 遇到的问题 | 处理方式 |
| --- | --- |
| 用户名或密码不正确 | 用户名填写坚果云账号邮箱；密码使用第三方应用密码。若应用密码已撤销，重新生成后通过**修改连接**更新 |
| 目录不存在或不是有效 WebDAV 目录 | 核对地址是否为 `https://dav.jianguoyun.com/dav/`，不要使用首页、分享链接或文件地址 |
| 测试成功，但坚果云里没有备份文件 | 测试只检查连接。还需点击**立即与WebDAV同步**，检查预览并确认**保存到云端** |
| 恢复后没有 API Key 或原来的翻译服务 | 检查原备份是否包含敏感配置，以及新设备是否已开启敏感配置。仅有基础配置的备份不包含这些内容 |
| 云端备份已变化 | 检查其他设备是否刚同步过，重新生成预览并核对变更 |
| 无法连接或请求过于频繁 | 检查网络和服务器地址；若达到坚果云访问频率限制，稍后再试，避免连续重复点击测试或同步 |
| 存储不足或文件过大 | 检查坚果云剩余空间；配置 JSON 上限为 20 MiB，密文文件上限为 32 MiB，也可改用本地备份 |

坚果云对第三方应用有访问频率等限制，具体以[官方说明](https://help.jianguoyun.com/?p=2064)为准。

## 换账号、停止使用和删除

点击**修改连接**可更换服务器、账号或密码。地址和用户名不变时，应用密码留空可保留已保存的密码；更换地址或用户名时，需要重新填写密码。修改连接后，原有预览不能继续使用。

**清除连接设置**只移除当前设备保存的 WebDAV 连接、应用密码和同步记录，保留本机配置及云端备份。如果需要撤销访问权限，在坚果云的**第三方应用管理**中撤销对应应用密码。

需要删除云端文件时，点击**删除云端备份**，核对账号和服务器地址，输入**确定删除**，再点击**删除备份**。此操作只删除 `FluentRead/fluentread-config.encrypted.json`，保留本机配置、API Key、连接设置和目录内的其他文件。删除成功后会清除本机的同步记录，之后手动同步仍可创建新备份。

取消或关闭确认不会删除文件；文件已不存在时，点击**完成**清理旧记录。若服务不支持删除或无法核验文件，可到坚果云网页中手动删除。回收站、历史版本和其他设备上的副本需要另行管理。卸载扩展、清除连接或撤销应用密码，都不会自动删除云端文件。

<summary>敏感配置与旧备份兼容</summary>

## 本次同步范围

基础配置备份排除整个敏感连接配置，包括 API Key、配置中的 OAuth Token、鉴权信息、翻译服务选择与模型、服务地址、自定义请求体及 URL 中的鉴权参数；私密提示词和未知字段也不上传。用于访问备份服务器的 WebDAV 地址、用户名及应用密码始终不进入备份或配置导出。

敏感配置的选择保存在当前浏览器中，完成、失败、取消、重开设置或切换备份方式与账号后仍保持，直到手动关闭。其他浏览器和设备需分别开启。保存或合并可纳入本机敏感信息，恢复只应用云端文件实际包含的内容；敏感配置在合并中隐藏具体内容，凭据、服务、模型和自定义连接按整组处理。

当前扩展仍可读取旧完整 v1 备份，默认只应用其中的普通设置。开启敏感配置后保存的完整备份沿用 v1 格式，旧扩展仍可读；新的基础配置备份采用 v2，旧扩展会安全拒绝，需升级后读取。升级前尚未确认的操作需要重新预览。

关闭敏感配置或仅恢复基础配置，不会从旧云端文件中移除敏感信息。只有确认保存或合并基础配置后，才会更新当前云端文件；这不会清除坚果云保留的历史版本或其他副本。文件保护和数据范围详见[隐私政策](/guide/privacy#webdav-云备份)。

<summary>其他 WebDAV 服务与版本保护</summary>

## 准备服务器连接

其他网盘、NAS 或服务器也可使用。填写服务商提供的**已存在目录的完整 WebDAV 地址**，账号需要读取、创建目录和写入权限；扩展会在该目录下使用同样的 `FluentRead/fluentread-config.encrypted.json` 路径。地址中不要放用户名、密码或查询参数。

例如，Nextcloud 的常见地址为 `https://cloud.example.com/remote.php/dav/files/你的用户名/`，可从文件设置中复制，参见 [Nextcloud 官方指南](https://docs.nextcloud.com/server/latest/user_manual/en/files/access_webdav.html)。优先使用有效证书的 HTTPS 和独立应用密码；HTTP 需要额外确认未加密传输的风险。扩展不会携带密码跟随重定向，请填写最终目录地址。

服务器需要支持 Basic 鉴权，以及 `PROPFIND`、`GET`、`MKCOL`、`PUT`，删除备份还需要 `DELETE`。连接测试通过后，仍需完成实际保存和恢复，确认服务兼容性。

## 云端版本保护

服务器提供强 ETag 时，扩展会通过版本条件写入和删除，拒绝覆盖预览之后其他设备的修改。扩展依次从下载响应头、文件的 `DAV:getetag` 属性、`HEAD` 响应头获取版本；必要时重读并核对文件内容。首次创建也使用条件请求，防止覆盖已有文件。

缺少强 ETag 时，兼容模式会在保存、合并或删除前重新读取备份，核对内容是否与预览一致；写入后读回核对，删除后确认文件不存在。坚果云提供无引号 ETag 时，扩展在内容核验后使用可用标识提交条件请求；完全没有可用标识时，只能检查文件是否仍存在。内容核验无法原子阻止核验后发生的并发修改，因此需要避免多台设备同时同步。

鉴权、网络、损坏文件和条件请求失败都会中止操作，不会通过无条件覆盖重试。协议细节见 [WebDAV 标准 RFC 4918](https://www.rfc-editor.org/rfc/rfc4918)。

</details>
