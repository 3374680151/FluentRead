# 翻译统计

打开 **设置 → 翻译统计**，了解翻译请求的数量、速度和失败原因，帮助选择服务、调整请求频率。

<GuideVisual kind="stats" />

## 先看概览

选择今天、近 7 天或近 30 天，再按服务或模型筛选。

| 指标 | 怎样理解 |
| --- | --- |
| 翻译请求 | 请求次数与成功率；错误和超时分别统计，离开页面造成的取消不算失败 |
| 翻译文本 | 请求中的原文字符数、段落数和数据量 |
| 平均耗时 | 从发起请求到收到结果的时间；同时提供 P95、最长耗时和服务等待时间 |
| 缓存复用 | 直接使用已有译文、无需再次调用服务的段落比例 |

趋势图可切换请求数、平均耗时和文本量。

## 比较翻译服务

在 **服务表现** 中点击列名排序，点击服务行查看对应记录，再次点击取消筛选。耗时只统计真正调用服务且成功的请求，不包含直接返回的缓存结果。

**P95** 表示约 95% 的请求在这个时间内完成，是根据耗时分布估算的值。批量请求文字更多，通常耗时也更长；可结合每行的每秒字符数比较。

使用免费翻译时，先选中免费服务，再查看 **免费翻译线路**。一次请求可能失败后换线，因此线路尝试次数会多于请求数，线路耗时也只统计成功尝试。需要调整时，打开 **翻译服务 → 免费翻译**，修改启用线路和顺序。

## 排查慢请求和失败

查看耗时与请求大小分布，判断是少数长请求，还是整体变慢。失败原因会区分密钥或权限、频率或额度、超时、网络等问题。频率限制较多时，可在 **高级设置** 中降低并发数或每秒请求数。

**请求记录** 提供时间、服务和模型、大小、状态与耗时。按状态筛选或按 **最慢** 排序，可快速找到异常请求。

| 请求来源 | 含义 |
| --- | --- |
| 服务请求 | 文字发送给翻译服务 |
| 缓存命中 | 全部段落使用已有译文 |
| 部分缓存 | 一部分使用缓存，其余调用服务 |
| 合并请求 | 与另一个进行中的相同请求共用结果 |

## 保存与清除

统计保存在当前浏览器，保留最近 5,000 条请求记录和 90 天的每小时汇总。**清除统计** 不会删除翻译缓存、模型用量或设置。

AI Token 用量请查看 [模型用量](/guide/model-usage)。
