# 输入框翻译

在聊天、邮件等网页中写好内容，再把它翻成需要的语言。译文可以替换原文，也可以和原文一起保留；流畅阅读不会自动发送回复。

<GuideVisual kind="input" />

## 开启与设置

1. 打开**设置 → 翻译设置 → 输入框翻译**并开启功能。
2. 选择目标语言、触发方式和输出方式。未单独指定服务时，跟随网页翻译服务。
3. 在输入框中写好文字，连续按三下选定的**空格、等号或短横线**，等待译文写回。原有 **Ctrl+Enter** 设置也可继续使用。

设置会自动保存。只调整语言或服务不会自动开启功能。密码框和代码编辑器不参与翻译。

## 保留双语回复

| 输出方式 | 翻译后显示 |
| --- | --- |
| 替换原文（默认） | 用译文替换输入内容 |
| 原文在前，译文在后 | 保留原文，下一行追加译文 |
| 译文在前，原文在后 | 先显示译文，再换行显示原文 |

双语输出需要支持换行的输入框。单行输入框会保留原文并提示原因；支持的富文本编辑器会尽量保留段落、加粗和链接等格式。

## 取消与恢复

翻译期间按 **Esc** 或点击**取消**即可停止。继续编辑也会取消翻译；离开富文本编辑器后，迟到的译文不会把焦点拉回。

翻译完成后，提示中会提供**恢复原文**，请在再次编辑前使用。富文本恢复先找回文字；链接、@提及等格式可用编辑器的撤销恢复。如果编辑器拒绝自动写入，可从提示中复制译文并手动粘贴。

失败后点击**重试**即可重新翻译。旧结果不会覆盖后来编辑的内容，触发时输入的字符也不会留在原文中。

## 翻译输入内容

**连按速度**决定相邻两次按键之间的最长间隔，默认为 1000 毫秒，可调为 200～2000 毫秒。容易误触时调短，连按不易成功时调长。长按和输入法选词不会当作三连按。同一内容仍在翻译时，重复触发会继续等待当前请求。

## 调整 AI 提示词

选择支持提示词的 AI 服务后，可调整语气和翻译要求。模型留空时使用服务默认模型；<code v-pre>{{origin}}</code> 表示原文，<code v-pre>{{to}}</code> 表示目标语言。

提示词留空会使用内置默认值，也可点击**从默认提示词开始编辑**再修改。恢复默认只影响当前提示词。
