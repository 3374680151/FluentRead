# 调整某个网站的正文范围

某个网站总是漏掉正文，或你希望导航、作者信息保持原文时，先按[网站阅读范围](/config/site-adaptation)排查。日常自动翻译与网站禁用只需设置网站偏好，无需编写规则。

需要精确控制区域时，进入**设置 → 工具与学习 → 网站规则 → 正文适配**。可视化编辑仍需要 CSS 选择器；不熟悉网页结构时，可反馈网址和目标区域。

## 从已有规则开始

1. 先导出规则备份，再搜索网站名、域名或规则标识。
2. 打开规则详情，选择**基于此规则自定义**，也可新建规则。
3. 每行填写一个域名、路径或 CSS 选择器；CSS 内的逗号不会拆成多条。
4. 选择**补充识别**，在通用正文上增加区域；或选择**限定范围**，只翻译声明的正文。
5. 点击**保存并应用**，确认保存成功后检查真实网页。

切换设置分类会保留草稿，但关闭或刷新页面仍可能丢失未保存内容，请先保存或导出。保存失败时表单会保留。规则标识自动生成，可在高级选项中修改。

同标识的自定义规则会完整覆盖内置规则；删除这条自定义规则并保存后恢复内置版本，原有停用状态保留。其他设置页更新了规则时，当前草稿不会自动覆盖它；先导出草稿，再恢复最新配置并合并修改。

## 保存后怎么检查？

在**生效预览**中输入完整 HTTP(S) 网址，查看网站偏好、命中规则及优先级。预览不访问网站，也不检查实际正文、网页权限、语言过滤或服务连接。

1. 打开网站，恢复原文后重新翻译。
2. 检查标题、正文是否齐全，作者和按钮是否保持预期状态。
3. 滚动、展开评论或切换文章，检查后续内容。
4. 效果不对时，停用自定义规则或恢复备份。

开启**识别全部节点**后，只使用声明支持该范围的适配规则；高级字段为 `allScopes`。

## 导入与备份

展开**JSON 与备份**可导入、导出或进入**高级 JSON 编辑**。编辑结果先留在草稿，点击**保存并应用**后才生效。

导入默认合并，同标识规则整条替换，其他规则保留。模板重名但内容不同会拒绝合并，请先重命名。也可选择**替换整个草稿**，保存前可撤销。

网站规则包含在 Google Drive 和 WebDAV 的基础配置备份中，包括开关、停用列表、自定义规则和模板。旧备份未包含规则时会保留本机规则；需要迁移缺失规则时，从原设备重新备份或导入单独导出的规则 JSON。
