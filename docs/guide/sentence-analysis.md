# 词性与句法

看清一句话中各个片段的作用，帮助理解长句。

<GrammarDemo />

## 在网页中使用

1. 开启 **划词翻译**，选择 **卡片模式**。
2. 在 **AI 深入讲解** 中配置服务和模型。
3. 选中一句话，打开翻译卡片，点击 **句法**。
4. 点击原句片段，或用左右方向键切换，查看对应说明。

上方保留原文顺序，下方标出句子成分与词性。两者含义不同：名词可以在一句话中作主语，也可以在另一句话中作宾语。

## 标注不完整时

分析由所选 AI 生成，适合作为学习参考。回答无法与原句对齐，或格式不受支持时，卡片会保留文字讲解；可重试或换用其他模型。

打开卡片不会调用 AI。主动点击学习操作后，才会将选中文字及你允许参考的上下文发送给已配置的服务。
