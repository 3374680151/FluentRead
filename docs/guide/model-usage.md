# 模型用量

在 **翻译统计 → 模型用量** 中查看 AI 服务和模型的请求次数、成功情况与用量趋势。

<GuideVisual kind="stats" />

## 查看用量

1. 选择时间范围，查看请求和用量的变化。
2. 点击服务或模型，筛选对应记录；再次点击可取消选择。
3. 在请求记录中按使用场景、状态或缓存筛选，查看失败和重试情况，也可导出记录。

**Token** 是模型处理文字的单位，不等于字数或单词数。输入 Token 来自发送的文字，输出 Token 来自模型回答；不同模型的计算方式也可能不同。服务提供明细时，页面会分别显示输入、输出和缓存用量。

## 怎样理解数字

记录包括已接入统计的 AI 请求，部分连接检查、重试和多段任务也会计入。服务没有返回的用量、未接入统计的功能和其他设备的请求可能缺失。费用请以服务商账单为准。

**输出速度（token/s）** 使用成功请求的输出 Token 和耗时计算，包含等待和传输时间。缺少必要数据时显示 `—`，输出为零时显示 `0`；平均耗时仍统计全部调用。

## 保存与清除

记录保存在当前浏览器，可在页面中导出或清除。它是用量记录，不是完整译文备份；清除也不会撤销已产生的服务费用。

只翻译需要的文字，并按需缩小 AI 参考的上下文，可减少用量。
