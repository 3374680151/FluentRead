# 使用 Chrome 本地翻译

Chrome 内置 AI 翻译在设备上处理文本。首次使用某种语言组合时，需要联网下载对应模型。

<GuideVisual kind="chrome-local" />

## 准备语言

1. 打开 **设置 → 通用设置 → 基础配置**，将默认网页翻译服务设为 **Chrome 内置 AI 翻译**。
2. 选择原文语言和目标语言，进入 **配置服务**，点击 **检查连接**。
3. 如果提示下载模型，保持设置页打开，等待进度完成。
4. 返回网页，重新发起翻译。

模型按语言组合准备。更换语言后可能需要再次下载；自动识别失败时，手动指定原文语言再试。

## 显示不可用怎么办？

可用性取决于 Chrome 版本、设备、管理策略和语言支持。先确认浏览器已更新、所选语言受支持，且首次下载时网络畅通。模型未准备好时，改用其他翻译服务即可继续阅读。

仍无法使用时，可按 [Chrome 官方排查说明](https://developer.chrome.com/docs/ai/debug-built-in-model) 检查本地模型状态。
