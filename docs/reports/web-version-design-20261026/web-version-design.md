# FluentRead Web 版功能与页面设计方案（2026-10-26）

> 本文承接 [web-version-feature-inventory-20261026.md](../web-version-feature-inventory-20261026.md) 的功能盘点，给出网页版的完整产品方案：信息架构、逐页面设计、配置项清单、设计系统与原型说明。原型位于本目录 `prototype/`，用浏览器直接打开 `index.html` 即可查看。

## 一、产品定位与范围

**FluentRead Web = 浏览器扩展能力的"工作台化"**：把扩展里的翻译引擎、40+ 翻译服务、词书学习、术语库、统计整体搬到自有网站，用户无需安装扩展即可完成翻译、阅读与学习；翻译请求经服务端代理转发（解决 CORS 与密钥归属），本地模型能力以标准 Web Worker + WASM 形态保留。

三大产品支柱：

1. **翻译**：文本 / 文档 / 网页（URL 代理渲染）/ 图片 / 字幕，五种形态共享同一服务层。
2. **学习**：单词本、复习、学习材料、阅读记录，形成"查—藏—学—回访"闭环。
3. **配置**：全部配置在网页内完成——服务与密钥、语言偏好、显示样式、朗读、快捷键、AI 偏好、备份同步。

## 二、设计系统（依据 ui-ux-pro-max 生成结果）

| 维度 | 决策 |
| --- | --- |
| 风格 | Flat Design + 微交互（生产力工具推荐样式）：无阴影无渐变、清晰线条、色块与排版驱动层级 |
| 主色 | 青绿 `#0D9488`（品牌延续扩展红色系以外的工具感，正式上线可切回品牌红 `#B8214E`，token 一处替换） |
| 强调色 | 橙 `#EA580C`（CTA/进行中状态），错误 `#DC2626` |
| 文本 | 主文 `#0F172A`，次文 `#475569`；中文正文 ≥15px，行高 1.7 |
| 字体 | Plus Jakarta Sans（拉丁）+ PingFang SC / Microsoft YaHei / Noto Sans SC（中文）；原型离线使用系统字体栈 |
| 状态反馈 | hover/active 仅颜色与透明度变化（150–200ms），不位移布局 |
| 无障碍 | 正文对比度 ≥4.5:1；控件边界 ≥3:1；全键盘可达、焦点环可见；`prefers-reduced-motion` 降级；图标全部内联 SVG，禁止 emoji 充当结构图标 |
| 主题 | 亮/暗双主题，CSS 变量驱动，跟随系统 + 手动切换 |
| 密度 | 工作台类页面标准密度（16–64px 间距档），阅读区放宽（24–96px） |

对比度修正说明：设计系统原始输出中 `On Primary #000`、边框 `#99F6E4` 在白底上不满足 4.5:1 / 3:1，落地时按钮填充采用加深主色 `#0F766E`（白字 ≥5:1），控件边框采用 `#94A3B8` 并以主色焦点环补强。

## 四、逐页面设计

### 4.1 工作台 index.html

目标：3 秒内开始一次翻译；回访用户直达"继续阅读"。

- 顶部问候条 + 默认语言对胶囊（自动检测 → 简体中文，点击可改）。
- 四张快捷入口卡：文本翻译 / 文档翻译 / 网页翻译 / 图片·字幕（大图标 + 一句说明）。
- 当前服务卡：默认服务名 + 状态点 + "更换"链接（→ services）。
- 最近文档列表：文件名、语言对、阅读进度条、更新时间、操作（继续阅读 / 导出）。
- 本周概览：翻译字符数、文档数、新收藏词、复习连胜。
- 空状态：首次访问显示"从粘贴一段文本开始"引导 + 示例文档按钮。

### 4.2 文本·写作 text.html

顶部三页签：**翻译 / 写作 / 对比**（对应扩展的划词翻译、写作助手、翻译中心）。

翻译页签：
- 工具栏：源语言 → 目标语言（自动检测默认）、交换按钮、服务选择器、词典开关、朗读按钮。
- 双栏编辑器：左侧输入（字数统计、粘贴、清空、示例）；右侧译文（复制 / 朗读 / 收藏到单词本 / 生成分享卡）。
- 词典条：输入为单个词时展示词性、音标、本地词典释义（ECDICT 数据）。
- AI 讲解侧板（阅读助手 Web 化）：讲解 / 句法分析 / 追问对话，流式输出演示。

写作页签：意图输入框 → 长度/语气/风格/身份选择 → 生成草稿 → 编辑后复制。

对比页签：同段输入并发 3 个服务并排卡片，显示各自耗时与凭据状态，可一键"采用此译文"。

### 4.3 文档翻译 document.html

- 顶部操作栏：导入新文档（弹窗：拖拽上传 / 在线 PDF URL / 从历史打开）、格式支持说明。
- 三区阅读布局：
  - 左栏：章节/页面目录，当前阅读位置高亮。
  - 中栏：阅读区，模式切换 原文 / **双语对照** / 仅译文；逐段翻译进度；段落级"重译/校订"右键菜单。
  - 右栏：导出（双语 PDF / DOCX / ZIP）、OCR 开关（扫描件）、术语库选择、字号。
- 顶部续读提示条："上次读到第 12 页 · 65%"。
- 原型以《Attention Is All You Need》类英文 PDF 为示例内容呈现双语对照态。

### 4.4 网页翻译 webpage.html

- URL 栏：输入网址 + 语言对 + "翻译此页"；下方站点兼容性提示（登录后内容不可用）。
- 代理渲染阅读视图：文章标题、逐段双语对照；工具条固定在阅读区顶部——显示模式（双语/仅译文/原文）、悬停模式（鼠标停留显示译文）、**智能高亮**（关键句着色）、字体大小、复制段落。
- 侧栏：本页服务临时切换、命中术语提示、收藏段落到学习材料、生成分享卡。
- 该页面承接扩展的：全文翻译、悬浮翻译（→悬停模式）、局部翻译（→段落点选）、划词翻译（视图内选词弹卡）、信息高亮。

### 4.5 图片·字幕 media.html

图片页签：
- 上传区 + 示例图演示块：原图/译图切换（滑块）、识别文字面板（无障碍阅读）、OCR 语言包管理（下载进度）。
- 漫画模式说明卡：气泡识别 + 原文擦除 + 排版回填；长图分段。

字幕页签：
- 上传 SRT/ASS/VTT 或视频文件、或输入字幕链接。
- 双语字幕预览表：时间轴、原文、译文（可编辑）；KTV 逐字高亮演示条。
- 导出：SRT / 双语 SRT / 纯译文。
- 视频本地转写（Whisper）作为"上传无字幕视频"的进阶入口，模型下载确认弹窗。

### 4.6 学习中心 learn.html

- 顶部统计：待复习、今日新学、连续天数。
- 四页签：
  - 单词本：词条卡（词、释义、出处材料链接、掌握度进度条、朗读）；筛选（词/表达/句、语言、来源）；导入导出。
  - 复习：翻卡演示（正面词 → 背面释义例句），认识/模糊/忘记三键，今日队列进度。
  - 学习材料：文档/网页/视频材料卡（缩略、进度、"继续"按钮直达原位置：文档段落 / 网页锚点 / 视频时间点）。
  - 阅读记录：AI 讲解历史（30 天），查看/恢复/删除。

### 4.7 术语库·校订 library.html

术语库页签：词库列表（名称、条目数、优先级拖放、启用开关、语言方向、站点范围）+ 词库详情表（源术语 → 固定译名，留空=保留原文；大小写匹配选项）+ 导入/导出 + 内置主题词库"添加为副本"。

个人校订页签：原文 → 原译 → 我的译法 三列表格，按站点/文档筛选，撤销；说明"校订将优先于服务译文生效"。

### 4.8 统计·用量 stats.html

翻译统计页签：概览卡（请求、字符、平均耗时、缓存命中率）+ 按服务分布条形 + 失败原因分布 + 最近请求明细表（时间、服务、字数、耗时、结果）。

模型用量页签：AI 服务 token 构成、近 30 天趋势、单请求明细、按项目（文档/网页/讲解）归因。图表以纯 CSS/SVG 条形呈现，正式版接 Chart 库。

### 4.9 翻译服务 services.html（核心配置页一）

- 左侧分类：免费服务 / 传统机器翻译 / AI 大模型 / 本地与自建。
- 右侧服务目录卡片网格：名称、类型徽标、状态点（默认/已配置/未配置/异常）、按钮（设为默认 / 配置）。
- 服务配置抽屉（以 DeepSeek 为例）：API Key 输入（密码态可显）、模型选择、连接测试（成功/失败/耗时）、每分钟请求限制、保存。
- 免费翻译服务详情：16 条线路池状态列表、自动换线开关。
- 自定义 OpenAI 兼容服务：新增表单（名称、Base URL、Key、拉取模型列表）。
- 安全说明卡：Key 仅存于本人账号，经服务端加密存储，不在前端日志出现。

### 4.10 偏好设置 settings.html（核心配置页二）

同页锚点导航 + 分区：

| 分区 | 配置项 |
| --- | --- |
| 语言与翻译 | 默认语言对、排除语言、自动翻译开关、翻译粒度（段/句）、站点规则（始终翻译/禁用名单） |
| 显示风格 | 译文样式预设（颜色/下划线/背景，实时预览块）、双语排列、译文/原文字号、主题（亮/暗/跟随系统）、界面语言 |
| 朗读 | 引擎（Edge 在线 / 本地 Kokoro / 系统语音）、音色试听、语速、自动朗读开关 |
| 快捷键 | 页面内动作键位表（翻译/交换/朗读/收藏…），录入框 + 冲突检测 |
| AI 助手 | 讲解风格与篇幅、写作默认长度/语气/身份、学习偏好（再次遇见开关）、API 限额 |
| 隐私与数据 | 翻译缓存管理（容量/清空）、本地数据导出、统计数据清除、匿名化开关 |
| 账号与同步 | 登录态、WebDAV / 云盘备份、多设备同步开关、登出与删除账号 |

## 六、全局组件规范

- **侧边栏**：分组（翻译/学习/词库/数据/配置），当前项高亮 + `aria-current="page"`；底部主题切换与账号块。
- **顶栏**：页标题 + 面包屑（二级页面）+ 页级主操作按钮。
- **服务选择器**：下拉单选，显示服务名 + 状态点；"管理服务…"固定末项跳转 services。
- **表单**：标签置上、行内校验（失焦触发，错误红字 + 图标）、保存反馈 toast；危险操作二次确认。
- **加载态**：按钮内 spinner、卡片 skeleton shimmer；`prefers-reduced-motion` 时改为静态占位。
- **空状态**：图标 + 一句说明 + 主行动按钮。
- **对话框/抽屉**：右滑抽屉承载配置表单，居中对话框承载确认与预览；焦点圈定，Esc 关闭。

## 七、响应式与无障碍基线

- 断点：375 / 768 / 1024 / 1440；375px 下双栏编辑器纵向堆叠，表格转卡片。
- 全部可点元素 ≥44×44 命中区；键盘 Tab 顺序与视觉一致；焦点环 2px 主色。
- 双主题分别验证对比度；暗色不直接复用亮色边框值。
- 标题层级严格 h1→h2→h3；图标伴随文字时 `aria-hidden`。

## 八、原型说明

- 目录：`prototype/`，入口 `index.html`，共享 `assets/app.css` 与 `assets/app.js`（页签切换、主题切换、少量演示交互）。
- 数据均为静态演示文案；文本翻译页的"翻译"按钮演示了请求→shimmer→出稿的交互流。
- 正式工程建议：Vue 3 + `<script setup>` + TS（复用 `src/ui` token 与组件思路），路由按本 IA 落地；翻译请求统一走 `/api/translate` 服务端代理（对应扩展 broker 的编排：缓存、去重、免费池换线、限流）。

## 九、后续接入自有服务的对接点

1. `POST /api/translate`：文本翻译代理（service、模型、语言对、上下文）。
2. `POST /api/document`、`GET /api/document/:id`：文档解析与任务进度。
3. `POST /api/fetch-page`：网页抓取与资源重写（webpage.html 后端）。
4. `/api/config/*`：服务密钥与偏好读写（账号体系）。
5. 学习中心/词库 CRUD + 导入导出。
