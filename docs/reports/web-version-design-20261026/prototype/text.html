AI 讲解 · streaming

DeepSeek

streaming 源自动词 stream（溪流 → 流动），加 -ing 构成动名词/现在分词。在计算机语境里指数据边产生边传输，与"先完整下载再播放"相对。

常见搭配：streaming media（流媒体）、live streaming（直播）、streaming translation（流式翻译，即边听边译）。

依据：选区上下文 "streaming translation systems had to process audio incrementally"——此处取"流式（边到边译）"义项。

问：streaming 和 real-time 有什么区别？

答：streaming 强调数据"分块连续到达"的传输方式；real-time 强调"响应延迟足够低"的体验目标。流式是手段，实时是目标——streaming translation 追求的正是 real-time 的体验。
