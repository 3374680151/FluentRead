# FluentRead 网站功能取舍（2026-10-30）

> 问题：插件的 28 个功能模块，网站上应该有哪些？
> 结论：**不是功能对等，是场景对等。** 插件里有一半能力本质是"入侵别人的页面"，
> 网站做不到也不该做。该搬的是"翻译 + 学习"的闭环，不是 28 个功能清单。
> 依据：逐个核对 `src/features/` 28 个模块的 `public.ts` 职责声明与 `src/providers/translation/` 能力。

---

## 一、先修正三条需求表述

| 原表述 | 实际 | 修正后 |
| --- | --- | --- |
| "站长只加一行代码" | 一行 `<script>` 只解决**加载**；还必须有人先把 API 服务部署到公网，并给站长一个站点 token | 一行 script + 一个 token + 我们托管服务 |
| "访客不承担任何配置成本" | 与"用户可以自定义模型"表面冲突 | **分层**：默认零配置，自定义模型是高级访客的可选项（见第四节） |
| "网站自带插件的所有功能" | 圈选翻译要屏幕捕获授权、视频字幕要劫持播放器、任意站注入做不到 | 自带**同等场景能力**，不是同等功能数量 |

---

## 二、四类判定

- **直接搬**：本来就是独立页面/纯前端，去掉扩展外壳即可用。
- **变形搬**：能力有用，但载体要换（注入 → 站内挂载，popup → 抽屉，后台 → 站长面板）。
- **不搬**：依赖扩展特权（任意站注入、`captureVisibleTab`、MAIN world 桥、offscreen 推理）。
- **新增**：只有网站才成立的（写作台、站长后台、云端词书）。

### 不搬（7）

| 模块 | 为什么不做 |
| --- | --- |
| `area-translation` 圈选翻译 | 需 `getDisplayMedia` 屏幕授权，一次授权一次弹窗，比装扩展还烦 |
| `video-subtitle` 视频字幕 | 依赖 MAIN world 劫持播放器；网站要做得自建播放器 + 服务端抓字幕，成本远超收益 |
| `information-highlight` 智能高亮 | 要跑本地小语言模型（WASM），首屏几百 MB，为高亮不值得 |
| `local-translation` 本地翻译模型 | 同上，模型下载成本高；服务端已有 40+ 线路 |
| `local-tts` 本地 TTS | 浏览器 `speechSynthesis` 已够用，没必要搬 80MB 音色包 |
| `paragraph-copy` 段落复制 | 浏览器原生复制/快捷键已覆盖，重复造轮子 |
| `page-notice` 页面通知 | 扩展内提示机制，网站用 toast 即可 |

## 四、自定义模型：三层设计（解决与"零配置"的冲突）

你提的"用户可以自定义模型"和"访客零配置"不是矛盾的——**是两种角色**。分三层，各管各的：

| 层 | 谁配 | 存在哪 | 访客感知 |
| --- | --- | --- | --- |
| **L1 站点默认模型** | 站长 | 服务端环境变量 | 无感，打开就能用 |
| **L2 站点可选模型池** | 站长勾选几个模型 | 服务端 | 顶部一个下拉，只能选站长开的 |
| **L3 访客自带模型** | 高级访客自己填 key | 本机 localStorage | 默认折叠在"高级"里，不填也完全可用 |

规则：
- L3 的请求**直连**访客自己的端点，不经我们的服务端，不占站点额度。
- L3 填错不影响 L1 兜底——调用失败自动回落站点默认模型，并提示一句"已切回默认模型"。
- 站长的 L2 下拉里，每个模型标注"质量/速度/成本"三档，避免访客乱选。

这套设计正好复用扩展已有的 `custom-*` 动态注册与模型列表拉取（`/api/ai/models`），
服务端只需把"可用模型清单"下发，不需要重写适配层。

## 五、网站最终该有的功能（导航映射）

| 导航 | 功能 | 来源 |
| --- | --- | --- |
| **写作台** | 双栏中英对照、输入框直译、术语锁定、AI 起草、导出 | 新增 + 写作助手 + 输入框翻译 + 术语库 |
| **文档翻译** | 导入 → 双语对照 → 导出、历史续读 | 文档翻译 |
| **阅读** | 站内正文整页对照、悬浮段译、AI 讲解 | 全文翻译 + 悬浮翻译 + 阅读助手 |
| **学习中心** | 单词本、翻卡复习、导入导出、学习统计 | 单词本 + 阅读助手 |
| **翻译中心** | 多服务横向对比 | 翻译中心 |
| **偏好设置** | 语言对、朗读、主题、快捷键、**自定义模型（L3）** | 设置 + 快捷翻译 |
| **站长后台** | 模型与额度、域名白名单、术语库下发、用量看板、连通性诊断 | 新增（设置 + 统计 + 诊断） |
| **嵌入 SDK** | 划词/点词/悬浮球/收藏，站长一行引入 | 划词 + 悬浮球 + 单词本 |

## 六、优先级收口

**P0（必须做，缺一个就不成立）**
划词翻译、点词词典、写作台、文档翻译、术语库、单词本、复习调度、悬浮球、双层设置、整页对照、自定义模型 L1/L2。

**P1**：AI 讲解、翻译中心、悬浮翻译、快捷键、诊断、L3 自带模型。

**P2**：分享卡片、个人校订、局部翻译、图片翻译、站长统计与用量。

**不做**：圈选、视频字幕、智能高亮、本地模型、本地 TTS、段落复制、页面通知。
