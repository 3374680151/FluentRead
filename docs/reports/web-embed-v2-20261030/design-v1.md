# FluentRead 网站版 完整设计（V1，2026-10-30）

> ⚠️ **方向已更正（2026-10-31）**：本文把"写中文文档、出英文"当作核心场景（动线 B），
> 以及"左中文右英文"的布局，**都是错的**。真实需求是
> **左边写英文、右边看中文回译**，纠错是核心功能。
> 以 `FluentRead-Go/docs/10-requirements.md` 为准；本文其余结构设计仍可参考。

> 范围：把插件能力做成一个可部署在服务器上的网站（含站长后台），访客零安装、零配置。
> 本文只做设计，不含实现。分两个视角：**第四部分＝用户使用**，**第五部分＝管理员配置**。
> 前置文档：`requirements.md`（需求基线）、`feature-decisions.md`（28 模块取舍）。

## 零、三条设计原则

1. **零配置优先于功能丰富。** 任何需要访客先填东西才能用的功能，默认关闭，而不是弹窗索要。
2. **默认能用，高级可调。** 站长配一次，全站生效；想调的人能调，不想调的人看不见。
3. **失败要说人话。** 每条失败路径都必须告诉用户"发生了什么、还能怎么用"，不允许只转圈或只报错码。

## 一、角色与权限

| 角色 | 谁 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| **访客** | 打开你网站的人 | 翻译、划词、查词、收藏、复习、导出自己的词书 | 改站点配置、看别人数据 |
| **高级访客** | 想用自己的模型的人 | 额外可填自己的模型（本机保存，直连，不占站点额度） | 影响其他访客 |
| **站长** | 你 | 配置模型、额度、域名白名单、术语、外观；看用量与诊断 | 看访客的私人词书内容 |
| **部署者** | 服务器运维 | 环境变量、域名、证书、数据库备份 | 业务配置走后台即可，不必登服务器 |

**关键约束**：访客的所有数据（词书、术语、历史）默认属于**访客自己**；站长只能看聚合用量，不能看明细。

## 二、信息架构

访客侧 6 个页面 + 嵌入 SDK；管理侧 1 个后台（内含 8 个分组）。

| 分区 | 页面 | 一句话职责 | 对应插件模块 |
| --- | --- | --- | --- |
| 翻译 | **写作台** `/write` | 中英双栏，边写边译，术语锁定 | 写作助手 + 输入框翻译 + 术语库 |
| 翻译 | **文档翻译** `/docs` | 导入文档 → 双语对照 → 导出 | 文档翻译 |
| 翻译 | **翻译中心** `/compare` | 同段多服务横向对比 | 翻译中心 |
| 阅读 | **阅读** `/read` | 站内正文整页对照、悬浮段译 | 全文翻译 + 悬浮翻译 |
| 学习 | **学习中心** `/learn` | 单词本 + 翻卡复习 + 导入导出 | 单词本 + 阅读助手 |
| 配置 | **偏好设置** `/settings` | 语言、朗读、主题、自定义模型 | 设置 + 快捷键 |
| 管理 | **站长后台** `/admin` | 模型、额度、域名、术语、诊断、用量 | 设置 + 统计 + 用量 + 诊断 |
| 嵌入 | **SDK** `fluentread-sdk.js` | 任意站一行接入，划词/点词/悬浮球 | 划词 + 悬浮球 + 单词本 |

> 与旧版差异：去掉"文本翻译"独立页（能力并入写作台与翻译中心），新增写作台、文档翻译、站长后台。

## 三、规划

| 阶段 | 交付 | 依赖 | 出口标准 |
| --- | --- | --- | --- |
| **M0 能上线** | 静态站 + API 服务 + 站点级模型配置 + 嵌入 SDK | 服务器与域名 | 陌生设备打开即译，全程零配置 |
| **M1 能读** | 文档翻译、阅读对照、划词点词 | M0 | 导入一份英文文档能读完并导出 |
| **M2 能写** | 写作台、术语库、个人校订 | M0、M1 | 写一篇中文能出可用英文并保持术语一致 |
| **M3 能学** | 词书服务端化、复习调度、跨站同步 | M0 | 在 A 站收藏，B 站学习中心可见 |
| **M4 能管** | 站长后台完整（额度、白名单、用量、审计） | M0 | 站长不登服务器即可完成全部配置 |

顺序理由：M0 不做完，后面全是本地玩具；M1/M2 是内容场景，能立刻验证产品价值；M3 才需要账号体系；M4 放最后是因为前三个阶段能手工改环境变量顶着。

## 四、用户使用设计

### 4.1 三条主动线

**动线 A：读英文文档（最高频）**
打开文档 → 选中句子 → 气泡出译文 → 遇到生词点一下 → 词卡 → 收藏（自动带原句）→ 之后去学习中心复习。

**动线 B：写中文文档（你的核心场景）**
进写作台 → 粘贴中文 → 分段出英文 → 术语自动锁定 → 不确定的短语选中查证 → 逐段校对 → 导出 Markdown。

**动线 C：处理一份文件**
进文档翻译 → 拖入文件 → 段落级双语 → 切换只看译文 → 导出双语 Markdown。

三条动线的共同点：**任何一步都不出现"请先配置"。** 配置只出现在设置页里，且是可选。

### 4.2 写作台 `/write`

**布局**：顶部工具条 + 左源文 / 右译文双栏 + 右下悬浮球。

**顶部工具条**
| 控件 | 行为 | 默认 |
| --- | --- | --- |
| 语言对 | 中文→English / English→中文，一键互换 | 中文→English |
| 风格档 | 学术 / 正式 / 简洁 / 口语 | 学术 |
| 模型 | 下拉，只列站长开放（L2）；每项标"质量·速度·成本" | 站点默认 |
| 术语状态 | "术语 3 条生效"，点击展开查看与开关 | 跟随全局 |
| 操作 | 翻译本段 / 全部翻译 / 导出 | — |

**编辑区交互**
- 按段落切分，每段独立翻译、独立重试。**单段失败不阻塞其他段。**
- 触发方式：`Ctrl+Enter` 翻译全部；光标所在段 `Ctrl+Shift+Enter` 只译本段。不做输入即译（写作时会打断思路）。
- 译文段可**直接编辑**（个人校订），改过的段标一个小标记，重译时弹确认"是否覆盖你的修改"。
- 段级悬浮操作：重译 / 换模型 / 复制 / 朗读。
- 选中中文词或短语 → 气泡：译文 + "锁定为术语" + 收藏 + 朗读。
- 选中英文词 → 气泡：音标 + 词性 + 释义 + 例句 + 收藏 + 朗读 + 替换。

**术语锁定**
- 命中术语的词在两侧都以虚线下划线标出，悬停显示"已锁定：检索增强生成 → retrieval-augmented generation"。
- 翻译时把术语作为约束传给模型；模型输出若未采用，**界面标黄并提示"该段未遵循术语"**，提供一键修正。
- 这是"全篇术语一致"的唯一可靠实现方式，不能只靠提示词。

**导出**：Markdown（双语并排 / 仅译文 / 带术语表附录）、纯文本、复制全文。

**空态**：一个"载入示例段落"按钮，点了就有一段中英对照示例，让用户立刻看懂这页干什么。

### 4.3 文档翻译 `/docs`

**三步结构**：导入 → 翻译 → 阅读导出。

| 步骤 | 界面 | 细节 |
| --- | --- | --- |
| 导入 | 大拖拽区 + "粘贴文本" 页签 | 支持 `.txt` `.md`；PDF/DOCX 标"即将支持"而不是假装支持 |
| 翻译 | 进度条 n/N 段，可中断 | 并发 3 段；失败段落标红，可单段重试 |
| 阅读 | 左原文右译文，滚动同步 | 视图切换：对照 / 仅译文 / 仅原文 |
| 导出 | 双语 Markdown / 仅译文 / TXT | 文件名沿用原文件名 |

**长文档保护**：超过 200 段先提示"这会消耗较多额度，预计 X 次请求，是否继续"。

**历史**：最近 10 篇留在本机，点击续读（含已译段落，不重复请求）。

### 4.4 阅读 `/read`

给站内文章用。正文每段下方插入译文行，默认折叠，点段首的"译"字展开该段。

| 模式 | 效果 | 适用 |
| --- | --- | --- |
| 段落对照（默认） | 段下插一行浅色译文 | 精读 |
| 悬浮 | 鼠标停在段落上浮出译文 | 快速浏览 |
| 仅译文 | 原文淡化，译文为主 | 已经读懂原文结构时 |

顶部一个总开关，右下悬浮球同步状态。整页翻译有进度提示，可随时停止并保留已译部分。

### 4.5 划词与点词（站内 + SDK 共用一套）

| 选中内容 | 弹出 | 内容 |
| --- | --- | --- |
| 单个单词 | 词卡 | 音标、词性、释义、例句、收藏、朗读 |
| 短语 / 句子 | 译卡 | 译文、复制、朗读、收藏（带原句） |
| 整段 | 译卡（紧凑） | 译文、复制、朗读 |

规则：
- 鼠标松开 400ms 内出现，位置贴着选区，不遮住被选文字。
- `Esc` 或点击空白关闭；连续选词时旧卡自动让位，不叠罗汉。
- 词卡里"收藏"成功后按钮变"已收藏"，**不弹 toast 打断阅读**。
- 词典查不到时，明确显示"未收录，以下为机器翻译"，不伪装成词典释义。
- SDK 版与站内版共用同一套组件与词书，视觉一致。

### 4.6 学习中心 `/learn`

三个页签：**单词本 / 复习 / 统计**。

**单词本**
- 列：词 / 释义 / 来源站点 / 掌握状态 / 下次复习。
- 筛选：类型（词/短语/句）、状态（新学/学习中/已掌握）、来源站点。
- 操作：编辑释义、标记掌握、删除（10 秒内可撤销）。
- 批量：导出 JSON（与浏览器扩展互通）、导出 Anki TSV。

**复习**
- 队列：到期老词优先，每批最多 10 个新词。
- 卡片正面：单词 + 挖空原句（把该词挖掉，保留上下文）。
- 卡片背面：释义 + 完整原句 + 来源链接。
- 两键评分：**忘了**（10 分钟后重来）/ **记得**（1、3、7、14、30 天递进）。
- 键盘：`1` 忘了、`2` 记得、`空格` 翻面。全程不用鼠标。

**统计**：收藏总数、待复习、已掌握、今日新学、连续学习天数。

### 4.7 翻译中心 `/compare`

一段文本 → 勾选 2–5 个服务 → 并发翻译 → 横向卡片对比（服务名 / 译文 / 耗时 / 成功或失败原因）。
用途是"选一个靠谱的服务"，所以**必须显示真实耗时与失败原因**，不能只显示成功的那几个。

### 4.8 访客设置 `/settings`

| 分组 | 项目 |
| --- | --- |
| 翻译 | 默认语言对、默认服务、失败自动换线 |
| 阅读 | 划词弹卡开关、悬浮球开关、默认阅读模式 |
| 朗读 | 语速（0.5–2.0）、音色、自动朗读译文 |
| 外观 | 浅色 / 深色 / 跟随系统 |
| 高级 | **自定义模型（L3）**：Base URL、Key、模型名、测试连接 |
| 数据 | 导出全部数据、清空历史、清空词书 |

高级分组默认折叠，文案写明："不填也能正常使用，填了会用你自己的模型，不占站点额度。"

### 4.9 六态设计（每页都必须有）

这是验收的硬指标，缺一个态就算未完成。

| 态 | 表现 | 例子 |
| --- | --- | --- |
| 加载 | 骨架屏或进度，不用无限转圈 | 文档翻译显示 n/N |
| 空 | 说明 + 一个可点的动作 | 词书为空 → "去读一篇文章，选中生词点收藏" |
| 失败 | 原因 + 重试 + 备选 | "微软线路超时，已自动换到腾讯" |
| 超时 | 明确的秒数 + 取消 | "已等待 20 秒，可取消" |
| 限额 | 剩余额度 + 恢复时间 + 降级方案 | "今日额度已用完，仍可用免费线路" |
| 未配置 | 说明缺什么 + 谁能配 | "本站未开启 AI 讲解，联系站长开启" |

## 五、管理员配置设计

### 5.1 后台结构

后台 `/admin` 分 8 组。左侧二级导航，右侧表单。**所有配置写服务端，不写浏览器。**

| 分组 | 解决什么问题 | 配置项数 |
| --- | --- | --- |
| 概览 | 现在健不健康 | 只读 |
| 模型 | 用哪个模型、访客能选哪些 | 8 |
| 额度与限流 | 别被刷爆 | 5 |
| 域名与接入 | 谁能嵌入、token 怎么发 | 4 |
| 术语库 | 全站统一译名 | 3 |
| 外观 | 悬浮球、气泡、主题 | 4 |
| 诊断 | 上游通不通 | 只读 + 一键检测 |
| 用量 | 花了多少 | 只读 + 导出 |

### 5.2 配置项全表

| 配置项 | 类型 | 默认 | 作用范围 | 生效 |
| --- | --- | --- | --- | --- |
| `ai.baseUrl` | URL | 空 | 全站 AI 请求 | 即时 |
| `ai.apiKey` | 密钥 | 空 | 全站 AI 请求 | 即时（不回显，只显示后四位） |
| `ai.model` | 文本 | 空 | 默认模型（L1） | 即时 |
| `ai.temperature` | 0–1 | 0.3 | 翻译稳定性 | 即时 |
| `ai.maxTokens` | 整数 | 2048 | 单次输出上限 | 即时 |
| `ai.pool` | 多选 + 标签 | 空 | 访客可选的模型（L2） | 即时 |
| `ai.allowVisitorKey` | 开关 | 开 | 是否允许 L3 自带模型 | 即时 |
| `freeServices` | 多选 | 全部 | 免费线路启用范围 | 即时 |
| `quota.dailyPerVisitor` | 整数 | 200 | 单访客每日请求 | 即时 |
| `quota.dailyPerSite` | 整数 | 20000 | 单站点每日 | 即时 |
| `quota.ratePerMinute` | 整数 | 30 | 单 IP 每分钟 | 即时 |
| `quota.onExceed` | 枚举 | 降级免费线路 | 超限行为（拒绝/降级） | 即时 |
| `site.allowOrigins` | 域名列表 | 空（仅本站） | 允许嵌入的域名 | 即时 |
| `site.tokens` | 列表 | 自动生成 | 每域名一个 token | 即时 |
| `site.sdkDefaults` | JSON | `{ball:true,selection:true,to:"zh-Hans"}` | SDK 默认行为 | 下次加载 |
| `glossary.global` | 表格 | 空 | 全站术语 | 即时 |
| `glossary.enforce` | 枚举 | 提示 | 强制 / 提示 / 忽略 | 即时 |
| `ui.ballEnabled` | 开关 | 开 | 悬浮球默认显示 | 即时 |
| `ui.bubbleTheme` | 枚举 | 跟随系统 | 气泡配色 | 即时 |
| `ui.brandName` | 文本 | FluentRead | 显示名 | 即时 |

> 环境变量（部署者级）：`FR_AI_BASE` `FR_AI_KEY` `FR_AI_MODEL` `FR_AI_MODELS` `FR_SITE_TOKEN`
> `FR_ALLOW_ORIGINS` `FR_DAILY_QUOTA` `FR_RATE_LIMIT` `FR_WEB_PORT` `FR_DB_PATH`。
> 后台改动覆盖环境变量；环境变量是"没有后台时的最小可用配置"。

### 5.3 模型三层怎么落地

| 层 | 配置位置 | 访客看到 | 失败时 |
| --- | --- | --- | --- |
| L1 站点默认 | 后台 `ai.*` | 什么都不用选 | 换免费线路 |
| L2 可选池 | 后台 `ai.pool` | 顶部一个下拉，只列池内 | 回落 L1 |
| L3 自带 | 访客设置页 | 默认折叠 | 回落 L1 并提示一句 |

站长视角的关键设计：**L2 不是"随便勾"，而是给每个模型打三个标签**——质量（高/中/低）、速度（快/中/慢）、成本（贵/中/便宜）。访客下拉里直接显示标签，避免他选了个又慢又贵的模型然后怪网站慢。

### 5.4 额度与防滥用

三层限流，任何一层触发都不返回 500：

1. **单 IP 每分钟** → 超限返回 429 + "请求太快，请稍等 X 秒"。
2. **单访客每日** → 超限降级到免费线路（不阻断），并提示"今日 AI 额度已用完，已切换免费线路"。
3. **单站点每日** → 超限全站降级，并在后台概览亮红灯。

站点 token 校验：SDK 请求带 `X-FR-Site`，服务端校验域名白名单。**未授权域名直接拒绝**，避免别人白嫖你的额度。

### 5.5 术语库下发

- 全局术语：站长维护，全站与所有嵌入站点生效。
- 站点术语：按域名覆盖全局。
- 访客术语：个人优先于站点，站点优先于全局。
- 冲突时以更具体的一层为准，并在写作台标黄提示。

### 5.6 诊断与用量

**诊断**（一键跑）：每个免费线路发一句固定测试句，显示通/不通、耗时、失败原因；AI 模型发一句 ping，显示是否可用与首字延迟。结果按时间倒序留最近 20 次。

**用量**：按日、按站点、按模型三个维度；展示请求数、成功率、P50/P95 延迟、token 估算与成本估算。支持导出 CSV。

### 5.7 权限与审计

- 后台登录：单管理员账号 + 密码（首启时设置），会话 7 天。
- 所有配置变更记一条审计：时间、项、旧值、新值（密钥只记"已更换"）。
- 危险操作（清空词书、重置 token、改白名单）需二次确认并写明影响。

## 六、数据模型

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| `visitor` | id、createdAt、firstSite | 匿名 id，存 cookie；登录后并入账号 |
| `word` | term、lang、translation、phonetic、pos、contextText、sourceUrl、state、dueAt、interval、ease | 词书核心，与扩展 schema 对齐以便互通 |
| `glossary` | term、translation、langPair、scope（global/site/user）、ownerId | 三层术语 |
| `doc` | id、visitorId、title、segments、createdAt | 文档翻译历史，段落级存 |
| `usage` | site、day、requests、failures、msP50、msP95、tokens | 聚合用量，不存原文 |
| `config` | site、key、value、updatedAt | 后台配置 |
| `audit` | at、key、oldValue、newValue、actor | 配置变更 |

**隐私红线**：`usage` 与 `audit` 不存原文、不存译文；词书内容只有访客本人可读。

## 七、接口契约（对外）

| 接口 | 方法 | 用途 | 鉴权 |
| --- | --- | --- | --- |
| `/api/config` | GET | 下发站点模型、语言、服务、SDK 默认值 | 无（不含密钥） |

| `/api/ai` | POST | AI 补全，缺 baseURL 时用站点配置 | 站点 token |
| `/api/ai/models` | POST | 模型列表 | 站点 token |
| `/api/glossary` | GET | 下发生效术语 | 站点 token |
| `/api/vocab` | GET/POST | 词书读写（M3） | 访客 id |

`/api/config` **绝不下发 apiKey**，只下发"是否已配置"和可选模型清单。

## 八、验收清单

每页按下表逐项过，全绿才算这页完成。

| 检查项 | 通过标准 |
| --- | --- |
| 零配置 | 空浏览器打开，不填任何东西能完成一次翻译 |
| 六态 | 加载/空/失败/超时/限额/未配置 都有对应界面 |
| 控制台 | 零报错、零告警 |
| 键盘 | 复习页可全键盘完成；写作台 `Ctrl+Enter` 可用 |
| 主题 | 浅色/深色下文字与边框都清晰 |
| 移动端 | 375px 宽不横向滚动 |
| 失败可见 | 每个失败都有原因与下一步 |
| 数据边界 | 站长后台看不到任何访客原文 |
