# FluentRead 嵌入式翻译能力（Web SDK）产品设计（2026-10-30）

> 目标：**访客在使用任何接入网站（尤其是文档站）时，自带 FluentRead 插件的翻译与学习功能，
> 无需安装浏览器扩展。** 本文完成插件功能盘点、外语学习者需求清单、嵌入式 SDK 产品设计，
> 作为开发与验收依据；验收采用"用户全功能走查 → 迭代修复"方式，至少 5 轮。

## 二、外语学习者需求清单（写/读文档场景）

P0（本轮实现）：
1. 读英文文档时，**选中即译**，不打断阅读；单词自动给词典而非机翻。
2. 看不懂的词**一键收藏**，自动带上下文原句（复习时看得懂为什么收藏）。
3. 收藏的词**能复习**（挖空句 + 两键评分），数据与本站学习中心同库。
4. 随时呼出的**快捷翻译**（悬浮球），可拖拽不挡内容。
5. 朗读单词与译文（跟读场景）。
6. 全部能力**不需要安装任何东西**，站长加一行 `<script>` 即可。

P1（下一阶段）：双语整页阅读、AI 讲解与追问、术语一致（写作场景）、更多目标语言配置面板。
P2：跨设备账号同步、站长级配置后台、统计看板。

## 三、嵌入式 SDK 设计（fluentread-sdk.js）

### 3.1 接入方式（一行代码）

```html
<script src="https://你的部署地址/fluentread-sdk.js"
        data-fr-to="zh-Hans" data-fr-ball="true" data-fr-selection="true"></script>
```

配置三来源合并（后者覆盖前者）：默认值 ← `data-fr-*` 属性 ← `window.FluentReadConfig`。
支持键：`serverUrl`（默认取 SDK 自身源）、`from`、`to`、`ball`、`selection`、`capture`、`theme`。

### 3.2 运行形态

- **零依赖单文件**，不依赖站点任何全局；UI 全部渲染在 **Shadow DOM**（`fr-sdk-root`）内，
  自带样式，不污染宿主页面、不受宿主 CSS 影响。
- 悬浮球：可拖拽（位置记忆于 localStorage `fr-sdk-fab-pos`）、双击复位、点按开合快捷翻译面板。
- 划词气泡：选中文本后自动弹出——词类文本（≤3 词）走 `GET /api/word`（ECDICT 词典优先，
  机器翻译兜底并如实标注来源），句子走 `POST /api/translate`（五条免费线路依次换线）；
  附复制、朗读、**收藏到生词本**（自动携带所在段落作为上下文）。
- 收藏链路：懒加载 SDK 源下的 `/assets/vendor/fr-vocabulary.js`（扩展同源词书领域层），
  写入 **SDK 服务源绑定的词书库**（与本站 learn.html 同库，收集的生词可在学习中心复习）；
  加载失败（如离线）降级为宿主站 localStorage 暂存并明确提示。
- 键盘可达：Esc 关闭气泡/面板；按钮均有 aria 标签。
- 卸载即销毁：无遗留计时器/监听（组件生命周期与页面一致）。

### 3.3 服务端配合（web/server.ts）

- `/api/*` 与 SDK/词书模块的静态资源响应追加 CORS 头（`access-control-allow-origin: *`），
  并处理 OPTIONS 预检——跨域嵌入站点才能调用翻译 API 与动态 import 词书模块。
- 不新增有状态接口；密钥类 AI 能力继续留在本站页（SDK 不传递任何密钥）。

### 3.4 演示页（embed-demo.html）

模拟"用户的文档站"：一篇英文文档（自有极简样式，不使用 FluentRead 设计系统）+ 顶部说明条 +
接入代码示例，页面只多出一行 `<script src="/fluentread-sdk.js" …>`。用于产品验收与站长接入示范。

## 四、验收清单（每轮迭代全量走查）

1. 嵌入演示页：悬浮球开合/拖拽/复位/快捷翻译（含失败换线提示）；划词句子翻译；选词/点词词典卡
   （音标/词性/释义/来源标注）；朗读；收藏生词（含上下文）；Esc 与空白处关闭。
2. 词书闭环：SDK 收藏 → 本站学习中心可见 → 复习两键评分 → 调度正确。
3. 本站页：工作台翻译/学习卡统计、学习工作台点词收藏、学习中心列表/复习/导入导出、服务页连通测试、
   设置页偏好持久化。
4. 非功能：控制台无报错；暗/亮主题可读；嵌入页宿主样式不受影响；每轮记录问题并全部修复。

## 五、里程碑

- M1（本轮）：SDK 上述能力 + 演示页 + CORS；≥5 轮用户走查迭代。
- M2：SDK 配置面板（目标语言切换）、双语整页（代理渲染）、AI 讲解接入学习中心。
- M3：跨设备账号同步（服务端词书），跨域嵌入的统一词书。
