# ChatGPT plan availability

**ChatGPT sign-in is not available in current public FluentRead releases.** The service directory hides this entry because the required OpenAI application and approval are not complete.

Choose an available provider under **Settings → Translation services**. If you previously saved a ChatGPT plan service or model, select another service for the features you use. Existing configuration and completed translations are retained.

A ChatGPT Plus or Pro subscription does not enable this integration in FluentRead or provide OpenAI API allowance. See the [official sign-in guide](https://developers.openai.com/siwc/quickstart). Maintainers can use [Apply for ChatGPT access](/en/guide/chatgpt-application) for the application process.
