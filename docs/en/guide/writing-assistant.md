# Writing assistant

Draft or improve replies beside supported Gmail and GitHub editors. Review the result, insert it, then decide when to send.

<GuideVisual kind="writing" en />

## Before you start

Open **Settings → Writing assistant**, enable it and choose an AI service and model. Configure missing details under [Translation providers](/en/config/translation-engines). Save your output language, reference language, length and tone in settings, or adjust them for the current draft.

## Draft a reply

1. Open a reply editor on a supported Gmail or GitHub page and select the writing entry beside it.
2. Improve an existing draft, or start from the current discussion. For a new email without context, enter the recipient, purpose and key points first.
3. Review names, facts and tone after generation. Add instructions to refine the draft if needed.
4. Select **Insert reply** to place it in the editor, or **Copy reply** to paste it yourself.
5. Check and send from the original website. The assistant does not send emails or post comments automatically.

If the original editor changes during generation, check its new content before inserting. Copy and paste manually when you need to preserve complex formatting.

## Bilingual replies

Choose different output and reference languages, then wait for the matching reference translation to finish. **Insert reply** inserts the main text; **Insert bilingual reply** in its menu inserts the main text followed by the reference translation.

GitHub keeps Markdown formatting. Gmail uses plain text.

## Improve an existing draft

Write in the reply editor before opening the assistant, then adjust the language, length or tone. Change the reference content to start a new draft.

## Reference text and stopping

Check the draft and visible discussion or email in **Reference content** before generating. Optional learning memory follows your saved preference and is not read in private windows.

Stop generation, close the panel or leave the page to cancel the request; generated text stays available. Clicking outside temporarily hides the panel. Reopen the entry for the same editor to review the draft and results. If you edit the original, change editors or navigate away, the assistant reads the current content again.

Drafts and reference content remain within this page session.

## Adjust or hide the entry

The entry menu can close it for this session, disable it on the current site or turn off the feature. Restore disabled sites under **Settings → Writing assistant**. Saved provider and style preferences are kept.

</details>

## Data

Generating or revising sends the necessary reference text, draft, instructions and any permitted learning memory to your selected AI provider. See [Privacy policy](/en/guide/privacy).
