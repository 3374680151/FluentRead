Getting Started with North Star

North Star is a lightweight documentation platform designed for teams that value clarity and velocity. This guide walks you through the essential concepts and helps you publish your first document in under ten minutes. If you have never worked with a static documentation generator before, do not worry: the workflow is deliberately mundane, and every command is idempotent.

Installation

Install the CLI globally with your preferred package manager. The installer will scaffold a minimal project, download the default theme, and register a local preview server that watches your files for changes.

npm install -g @northstar/cli
northstar init my-docs
cd my-docs && northstar dev

Writing content

Every document is a plain Markdown file. The first heading becomes the page title, and consecutive pages are stitched into a navigation tree based on the directory layout. You can annotate paragraphs with arbitrary metadata and reference other sections by stable anchors, which remain valid even when you reorder chapters.

Tip: ambiguous terminology is the enemy of good documentation. Keep a glossary of domain-specific expressions and use it consistently; the built-in linter will flag inconsistent phrasing before you publish.

Publishing

When you are satisfied with the preview, run the publish command. The generator compiles your content into static assets, purges stale fragments, and deploys the bundle to the storage backend configured in your project manifest. Incremental builds are deterministic: identical inputs always produce identical output.

  • Previews expire automatically after seven days of inactivity.
  • Every publish creates an immutable snapshot you can roll back to.
  • Search indexes are rebuilt incrementally, so large sites stay fast.

Troubleshooting

If the preview server fails to start, verify that the port is not already occupied and that your Node.js version satisfies the engines constraint. Stale caches can be discarded with a single command, and verbose logging will reveal which plugin swallowed an error. For anything else, the community forum is remarkably responsive.
